# i-dle 萌跑

基于参考视频制作的竖屏网页游戏，使用原生 HTML、CSS、JavaScript、Canvas 和 SVG，无构建步骤。

## 运行

```sh
python3 -m http.server 4173
```

浏览器打开 http://localhost:4173 。也可以直接打开 `index.html`；推荐通过本地服务器运行，以保持存档来源一致。

## 玩法

- 左右方向键 / A、D / 左右滑动：切换三条跑道。
- 上方向键 / W / 上滑：跳过路障。
- 下方向键 / S / 下滑：躲避横杆。
- 空格 / Esc / 暂停按钮：暂停和继续。
- 巴士需要换道避开；三颗心耗尽后结算。
- 初始速度 44 m/s，逐渐加速至 70 m/s；道路连续向左、向右弯曲，角色自动跟随道路转向，左右操作仍用于换道。
- 收集金币、磁铁和飞行道具；每 700 米切换城市 / 森林。
- 五位角色、21 首歌名选择、8 件装扮和 15 张角色卡。
- 记忆翻牌、30 秒打地鼠、抓娃娃、6 题合成旋律小游戏。
- 金币、角色、装扮、卡片和最佳距离保存在当前浏览器的 localStorage。

## 还原范围

按视频重绘粉彩界面、五位萌宠和城市场景。角色和卡片为 SVG 重绘，非原游戏素材；歌单保留参考中的歌曲名称，音频使用 Web Audio 合成伴奏，不包含原唱录音。猜歌使用合成旋律与文字提示。所有金币均为游戏内积分，不涉及支付。

## 验证

- JavaScript 语法检查；`node --test tests/runner-motion.test.cjs` 检查建筑滚动连续性、世界速度同步及弯道投影。
- 桌面与 390 × 844 移动视口实测。
- 选歌、角色、跑酷计分/受伤/暂停、翻牌通关奖励、抓娃娃结算、猜歌六题、打地鼠命中、装扮购买切换、卡册抽卡和刷新存档。
- 2026-10-12：验证左右弯道、换道/跳跃、暂停恢复及城市/森林切换。本机内置浏览器在桌面和 390 × 844 视口的多个 180 帧采样均约 60 FPS，平均游戏更新与绘制指令提交耗时 1.17–2.57 ms/帧（不包含 GPU 执行耗时）。
- 真机触感、原版歌曲与素材的逐像素一致性不在本次验证范围内。
